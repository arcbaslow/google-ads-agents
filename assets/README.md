# Documentation assets

- `hero.jpg`: README banner. The illustration was generated with Higgsfield (GPT Image 2.6); the title is typeset in Manrope.
- `icon.svg`: independent project symbol for documentation previews.
- `screenshot.png`: browser capture of real project output from the synthetic fixtures in `examples/demo/`.
- `banner.png`: earlier banner retained for existing links.

The screenshot renders the Markdown report in a documentation-only HTML viewer, not an application UI. Inputs contain no customer data or credentials. Vector assets follow the repository's MIT license.
